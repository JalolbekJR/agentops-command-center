## Resume Usage Notes

Use past-tense bullets only after the corresponding work exists. For now, accurate language is:

- Designed.
- Documented.
- Modeled.
- Planned.
- Created architecture foundation.

Avoid claiming:

- Deployed production system.
- Real customers.
- Live AI integrations.
- Production-grade security enforcement.
- Completed backend.
